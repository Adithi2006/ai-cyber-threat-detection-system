# AI Cyber Threat Detection and Network Monitoring System

## Project Overview

The **AI Cyber Threat Detection and Network Monitoring System** is a web-based cybersecurity application designed to monitor network activity in real time, detect potential threats, and provide security insights to users. The system analyzes live network data, identifies suspicious behavior, and generates alerts to help maintain secure and reliable network environments.

This project demonstrates how modern technologies such as **Artificial Intelligence concepts, real-time monitoring, and automated reporting** can be used to improve cybersecurity awareness and protection.

---

# Problem Statement

With the rapid growth of digital systems and internet usage, cyber threats such as malware attacks, unauthorized access, and network intrusions have become more frequent and complex. Many small organizations, educational institutions, and individual users lack affordable and easy-to-use tools to monitor their network activity and detect security risks in real time.

Traditional security systems often require advanced technical knowledge, expensive infrastructure, and manual monitoring, which makes them difficult to implement for everyday users.

Therefore, there is a need for a simple, intelligent, and automated system that can:

* Monitor network traffic continuously
* Detect suspicious activities
* Provide real-time alerts and reports
* Help users understand their network security status
* Improve overall cybersecurity awareness

---

# Proposed Solution

This project provides a **real-time network monitoring and threat detection platform** that automatically collects network data, analyzes activity patterns, and displays security information through an interactive dashboard.

The system uses a backend service to gather network statistics and a user-friendly web interface to visualize the data. It allows users to monitor their systems, identify potential risks, and take preventive actions to maintain network security.

# System Modules

## Home Dashboard

Displays real-time network information and system status with animated visualizations.

## Reports Section

Shows security reports, detected threats, and system activity logs.

## System Usage Section

Displays how many systems are using the application and when they were accessed.

## Monitoring Engine

Continuously collects network statistics such as:

* Packets sent and received
* Data transfer rate
* Active connections
* Network activity status

# How to Run the Project

Step 1 — Navigate to the project folder

```bash
cd backend
```

Step 2 — Start the backend server

```bash
python -m uvicorn main:app --reload
```

Step 3 — Open the website

Open your browser and go to:

```bash
http://127.0.0.1:8000
```
